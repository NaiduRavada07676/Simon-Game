# 🧠 Simon Game

An interactive **Simon Memory Game** built using **HTML, CSS, and JavaScript**.

The game challenges players to remember and repeat an increasingly long sequence of colors. Each successful round adds a new step to the sequence, making the game progressively more difficult.

## 🎮 Features

- 🧠 Memory-based gameplay
- 🎨 Color sequence generation
- 🔊 Interactive feedback
- 📈 Increasing difficulty
- 🏆 Score/level tracking
- ❌ Game-over detection
- 🔄 Restart functionality
- 📱 Responsive design
- ✨ Interactive animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
